# C++ Sayı Tahmin Oyunu 🎮

Bu proje, C++ programlama dilini öğrenirken geliştirdiğim interaktif bir 1-100 arası sayı tahmin oyunudur.

## 🚀 Özellikler
* `cstdlib` ve `ctime` kütüphaneleri kullanılarak her oyunda dinamik (rastgele) sayı üretimi.
* Kullanıcı dostu hak (`5 hak`) sistemi ve yönlendirmeler (`Yukarı / Aşağı`).
* Temel döngü (`while`) ve karar (`if-else`) yapıları ile kurgulanmıştır.

## 🛠️ Nasıl Çalıştırılır?
1. Depodaki `.cpp` dosyasını indirin.
2. Herhangi bir C++ derleyicisinde (Visual Studio, Dev-C++ vb.) açın ve derleyin.
3. Oyunu başlatıp tahminlerinizi yapmaya başlayın!

> *Not: Bu proje, 15 yaşındayken C++ programlama dilini öğrenirken geliştirdiğim ilk oyunlardan biridir.* 🎮
